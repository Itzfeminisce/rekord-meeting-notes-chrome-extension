# T6 Google connect and Calendar
Frames: V3GoogleConnect, V3Connections (Google rows), V3Start calendar card, V3Library "Coming up",
V3States "Start · nothing on the calendar" and "Start · calendar access lost". Rows: FRAMES.md for those.
Paths: lib/google.ts (new: auth, token, revoke), lib/calendar.ts (new), screens/GoogleConnect.tsx,
screens/Connections.tsx (new), screens/Start.tsx (calendar card only), screens/Library.tsx (Coming up only),
docs/v3/GOOGLE.md, tests.
- Auth: `chrome.identity.getAuthToken({interactive, scopes})` with the scopes the checkboxes allow; Disconnect →
  `removeCachedAuthToken` + revoke + clear settings.google. A 401 later → "calendar access lost" state.
- Calendar: list events for the chosen calendar from now-15 min to end of day; current = started ≤10 min ago or
  starting in ≤5 min. Fill meeting title, event (attendees, app from conference link) when recording starts.
- GOOGLE.md: exact owner steps (Cloud project, enable Calendar + Drive APIs, OAuth consent in testing with the owner
  as test user, Chrome-extension client for the fixed extension ID, put the ID in WXT_GOOGLE_CLIENT_ID).
- Tests: event matching windows, conference app detection, attendee mapping, disconnect clears state.
