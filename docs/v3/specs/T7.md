# T7 Share to Google Docs and view-only link
Frames: V3Share (Docs and link rows, include chips, More, Close), V3States "Share · saving", "Share · couldn’t save",
"Share · link copied". Rows: FRAMES.md V3Share (not the Notion row).
Paths: lib/share/gdocs.ts (new), lib/share/render.ts (new: meeting → HTML using the include choices, same content
rules as lib/export), screens/Share.tsx (new), screens/Summary.tsx (Share opens it), router, tests.
- Save: find or create a Drive folder "Rekord", upload the HTML as a Google Doc (multipart with
  mimeType application/vnd.google-apps.document). Re-sharing the same meeting updates its existing doc.
- Link: create permission `{type:'anyone', role:'reader'}`, copy the doc URL, ShareRecord.linkShared = true.
- Save ShareRecord on the meeting. Not connected → V3GoogleConnect first, then continue.
- Tests: render honours include choices, folder find/create, update-not-duplicate, error → Try again state.
