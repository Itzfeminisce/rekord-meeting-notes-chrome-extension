# T10 What's new and Chrome Web Store packaging
Frames: V3WhatsNew. Rows: FRAMES.md V3WhatsNew.
Paths: screens/WhatsNew.tsx (new), entrypoints/background.ts (onInstalled), App routing, package.json (zip script),
docs/v3/STORE.md (new), docs/privacy.md (new), tests.
- `chrome.runtime.onInstalled` reason 'update' with a newer version than settings.lastSeenVersion → show What's new
  once on next panel open; either button sets lastSeenVersion. Fresh installs go to Welcome, not What's new.
- `npm run zip` builds a store-ready zip (WXT zip). STORE.md: unlisted listing text in the product's voice, required
  screenshots list, permission justifications (one line each), and the owner's upload steps. privacy.md: plain-words
  policy (what leaves the computer and when, no tracking) suitable for the listing's privacy URL.
- Tests: version comparison and show-once logic.
