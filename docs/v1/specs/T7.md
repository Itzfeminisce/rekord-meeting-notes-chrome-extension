# T7 Wrapping up + Summary
Frames: design/frames/Processing.dc.html, design/frames/Summary.dc.html. Paths: screens/Processing.tsx, Summary.tsx,
lib/summarize.ts, tests.
- Processing: progress from pending chunk count (db) and `segment/added`; when `transcription/drained` arrives (or no
  pending), call `summarize(meetingId)`, set meeting status done, → summary. If the summary call fails, still save the
  transcript, set status done, and show the error with Retry.
- `summarize`: POST `${baseUrl}/chat/completions` (summary provider/model/key from settings + loadKeys), transcript as
  "[mm:ss] You/Others: text" lines plus notes and markers; ask for JSON matching `Summary` (overview, decisions,
  actions with optional owner, questions). Parse defensively (strip code fences); long transcripts are truncated to
  ~100k chars keeping start and end. Injectable fetch; tests for parsing and errors.
- Summary screen: title, date, duration, overview, decisions, action items, questions, the user's notes and markers;
  actions → transcript, export, new meeting (start). Regenerate button.
