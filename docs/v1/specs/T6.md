# T6 Start + Live
Frames: design/frames/Start.dc.html, design/frames/Live.dc.html. Paths: entrypoints/sidepanel/screens/Start.tsx,
Live.tsx, entrypoints/sidepanel/components/** (new files only), lib/live.ts, tests.
- Start: shows the current tab (title/favicon via `browser.tabs.query({active:true,currentWindow:true})`), Record →
  `recording/start {tabId}` → live. Recent meetings from db (→ summary), links to library and settings. If keys are
  missing show the reconnect prompt (T5's `reconnect()`).
- Live: elapsed clock, record dot (red, only here), mic/tab level meters from `recording/state`, transcript list fed by
  `segment/added` + initial db load, auto-scroll unless the user scrolled up. Notes input (Enter adds a Note at the
  current elapsed ms). Marker buttons Decision, Action, Question, Bookmark add a Marker at the current ms and show
  inline in the timeline. Show "about 10 s behind" hint. Stop → `recording/stop` → processing.
  Connection problems show the banner from T10 if it exists (otherwise leave a clearly named slot).
