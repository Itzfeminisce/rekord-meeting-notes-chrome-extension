# T1 core
Paths: lib/types.ts, lib/db.ts, lib/settings.ts, lib/messages.ts, lib/time.ts, entrypoints/sidepanel/** (router, shared
components, style.css), package.json/package-lock.json (deps), their tests, docs/v1/HANDOFF.md.
1. `lib/types.ts` = docs/v1/CONTRACT.md verbatim.
2. `lib/db.ts`: IndexedDB via the `idb` package, DB `rekord` v1, stores meetings, segments, notes, markers, chunks
   (index `meetingId` on all but meetings; chunks also index `status`). CRUD helpers used by later tasks: put/get/list
   by meeting, listMeetings (newest first), deleteMeeting (cascades), pendingChunks(meetingId?). Tests with
   `fake-indexeddb`.
3. `lib/settings.ts`: Settings in `browser.storage.local` with defaults (groq whisper-large-v3-turbo; summary groq
   `llama-3.3-70b-versatile`; keySource penv; penv penvhq/meeting-notes-taker/testing; language en; onboarded false);
   `getSettings`, `updateSettings(partial)`, `onSettingsChanged`. `PROVIDERS: Record<ProviderId, ProviderConfig>`
   (groq https://api.groq.com/openai/v1, openrouter https://openrouter.ai/api/v1, ollama http://localhost:11434/v1,
   openai https://api.openai.com/v1, anthropic https://api.anthropic.com/v1).
4. `lib/messages.ts`: typed `send(msg)` and `onMessage(handler)` over `browser.runtime` for the `Message` union;
   sending with no listener must not throw.
5. `lib/time.ts`: `formatClock(ms)` → "12:04" / "1:02:03", `formatDuration(ms)` → "42 min", "1 h 5 min".
6. Side panel router: a tiny in-memory router (no URL lib) with screens: welcome, permissions, connect, start, live,
   processing, summary, library, transcript, export, settings, error; route params (e.g. meetingId). First screen:
   welcome if `!settings.onboarded`, else start. Each non-welcome screen is a placeholder file
   `entrypoints/sidepanel/screens/<Name>.tsx` that later tasks replace. Move the existing Welcome into the router
   ("Get started" → permissions).
7. Shared components from the Welcome frame look (`design/frames/Main.dc.html`): TopBar (brand + right slot),
   Button (primary/secondary/ghost), Card, Tag (marker kinds), Spinner, EmptyState. CSS variables stay in style.css.
8. Write the Conventions section in HANDOFF.md (≤6 lines).
