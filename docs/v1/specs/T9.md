# T9 Export
Frame: design/frames/Export.dc.html. Paths: screens/Export.tsx, lib/export.ts, entrypoints/print/** (print page), tests.
- `toMarkdown(meeting, segments, notes, markers)`: title, date, duration, summary sections, notes, markers, transcript.
- Markdown: download `.md` via a Blob URL (`browser.downloads` not needed; use an <a download>). Copy to clipboard too.
- PDF: open `print.html?meetingId=` (an extension page that renders the same content, print-styled) and call
  `window.print()` so the user saves as PDF.
- Email draft: `mailto:` with subject = title and body = overview + decisions + actions (truncate the body to about
  1,800 chars and say it was shortened). Tests for toMarkdown and the mailto builder.
