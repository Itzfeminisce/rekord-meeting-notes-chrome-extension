# T4 Mic access (onboarding step 2)
Frame: design/frames/Permissions.dc.html. Paths: entrypoints/sidepanel/screens/Permissions.tsx,
entrypoints/permission/** (a small extension page), lib/mic.ts, tests.
- Chrome does not show permission prompts in a side panel, so "Allow" opens `permission.html` in a new tab, which calls
  getUserMedia({audio:true}), stops the tracks, shows a short done message and closes itself.
- The screen watches `navigator.permissions.query({name:'microphone'})` and moves on (→ connect) once granted; shows a
  denied state with how to fix it (chrome site settings for the extension). Back → welcome. Copy from the frame.
