# T3 Live action-item suggestions
Frame: design/frames/Suggest.dc.html. Paths: lib/suggest.ts, entrypoints/sidepanel/components/SuggestionCard.tsx,
Live.tsx (render cards + footer count only), lib/summarize.ts (include accepted AI actions only), tests.
- While Live is open and `features.liveSuggestions` is on: every 60 s, if segments exist after `suggestCursorMs`,
  call `chat` (json) with the last 3 minutes of lines plus existing action texts; ask for
  `[{text, owner?, due?, atMs}]`, max 3, only clear commitments. Advance `suggestCursorMs` on success only.
- Skip a run when the connection state is not ok or a run is in flight. Drop suggestions whose text closely matches an
  existing action (case/space-insensitive equality or one contains the other).
- Save each as a Marker {kind 'action', source 'ai', status 'suggested'}. Card under its moment in the transcript:
  editable text, owner/due line, "Add to actions" (accepted) and "Dismiss" (dismissed). Footer: "<n> actions added ·
  <m> suggestions waiting".
- Summary: accepted AI actions go into the prompt as actions; suggested/dismissed ones are ignored.
- Tests: scheduler (fake timers), cursor, dedupe, parsing, accept/dismiss persistence.
