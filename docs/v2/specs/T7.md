# T7 Connect never blocks on a bad key
Paths: lib/connect.ts, lib/connect.test.ts, entrypoints/sidepanel/screens/Connect.tsx, entrypoints/sidepanel/screens/Start.tsx
(reconnect banner copy only, if needed), entrypoints/sidepanel/style.css (append only).
Problem: Connect verifies only the transcription key and calls forgetAll() on failure, so one wrong key blocks onboarding.
- `checkKeys(keys, fetch?)`: check every loaded key against its own provider in parallel, cheaply: Groq/OpenAI/OpenRouter
  `GET {baseUrl}/models` (Bearer), Anthropic `GET https://api.anthropic.com/v1/models` (x-api-key + anthropic-version),
  Deepgram `GET https://api.deepgram.com/v1/projects` (Token). Result per key name: 'ok' | 'rejected' (401/403) |
  'unreachable' (network/5xx/timeout ~8 s). Never put key values in results, errors or logs.
- `pickProviders(results, settings)`: transcription = current if its key is ok, else the first ok of groq → openai;
  summary = current if ok, else first ok of groq → openai → openrouter → anthropic; diarization stays on only if the
  Deepgram key is ok. Returns the settings patch (full nested objects; updateSettings replaces nested objects whole).
- Connect (both penv and paste): after loading keys, show one row per key: name + "Works" / "Rejected" /
  "Couldn't check". Keep the keys (no forgetAll on a rejected key). Show the chosen providers with a small picker
  (transcription: Groq/OpenAI; assistant: Groq/OpenAI/OpenRouter/Anthropic/Ollama), limited to providers whose key is
  ok (Ollama needs none). Primary button "Continue" saves settings + onboarded:true → start.
  If no transcription key works: still allow continuing via "Continue anyway" (secondary), copy:
  "Rekord will record, and transcribe once a working key is added." → onboarded:true → start.
- Paste mode: the key fields follow the providers picked (at least one transcription key field), plus optional Deepgram.
- Start: if keys are loaded but the transcription key was rejected, show the existing reconnect banner with copy
  "Your transcription key was rejected. Fix it in Settings." linking to settings (do not block Record).
- Tests (fake keys, injected fetch): checkKeys statuses incl. timeout, pickProviders fallbacks, rejected key not wiped.
