# T2 Ask mid-meeting and after
Frame: design/frames/Ask.dc.html. Paths: lib/ask.ts, entrypoints/sidepanel/screens/Ask.tsx (new), router entry,
Live.tsx (Ask tab only), Summary.tsx ("Ask about it" button only), tests.
- `ask(meetingId, question)`: build context = title + `transcriptLines` + notes + markers (truncate like summarize),
  system prompt: answer only from this meeting; cite moments as [mm:ss]; say plainly when it wasn't discussed.
  Save an AskTurn before the call (question), update with answer/citations/error. Parse [mm:ss] → citations (atMs).
- Screen: turns in order; citation chips open Transcript at that moment; quick prompts "Catch me up" (last 5 min),
  "Open questions", "Actions so far"; Copy and "Save to notes" (creates a Note at the newest cited moment, else now).
  Footer line: "Answers come from this meeting’s transcript and notes."
- Works while recording (Live's Ask tab) and after (Summary → Ask about it). Hidden when `features.ask` is off.
- Errors use the existing connection states; a failed turn shows Retry.
- Tests: prompt building, citation parsing, persistence, error turn.
