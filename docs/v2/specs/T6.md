# T6 Name speakers screen, display names, Settings switches
Frames: design/frames/Speakers.dc.html, design/frames/Settings.dc.html. Paths: screens/Speakers.tsx (new), router
entry, Transcript.tsx ("Rename speakers" opens Speakers), Summary.tsx/Export (names via `transcriptLines`),
Settings.tsx (switches + Deepgram key status), Connect.tsx (optional Deepgram field on Paste only), lib/speakers.ts (save helpers), tests.
- Speakers screen: one card per label: talk time and line count, a quote (longest line), play a ~8 s sample from the
  recording at that line (blob URL + currentTime; hidden if audio already deleted), name input prefilled with the
  suggestion plus its evidence line, "These are the same person" merges two labels. Save → `speakers[*].name`,
  `speakerStep 'saved'`; Skip → 'skipped'. Then `deleteRecording` unless `keepAudio`. → Summary.
- Display: anywhere a speaker shows, use name, else "Speaker A", else "Others". You stays "You".
- Settings: switches for Ask, Live suggestions, Speaker names; "Keep audio files"; a line showing whether
  `DEEPGRAM_API_KEY` is loaded (never the value). Speaker names off when the key is missing, with a hint.
- Tests: save/skip/merge, display-name resolution, audio deletion rule.
