# T4 Continuous tab recording for diarization
Paths: entrypoints/offscreen/main.ts, lib/audio/recording.ts (new), entrypoints/background.ts (wiring only), tests.
- When a meeting starts with tab audio, `features.speakerNames` is on and a `DEEPGRAM_API_KEY` is loaded: start a
  second MediaRecorder on the tab stream only, same mimeType, 32 kbps, `timeslice` 30 s. Each dataavailable →
  RecordingPart {seq++}. The v1 chunk recorder is untouched.
- Offscreen has no storage API: send parts to the background, which writes them (same pattern as chunk saving).
- Pause/resume: `pause()`/`resume()` the recorder and append {atMs, durationMs} to RecordingMeta.pauses.
- Stop: final part flushed before the meeting moves to processing; set `speakerStep 'pending'`.
- Not recorded (step stays undefined) if the feature is off, no key, or mic-only meeting.
- Delete after names are saved/skipped (T6 calls `deleteRecording`) unless `keepAudio`. Deleting a meeting deletes it.
- Tests: part sequencing, pause bookkeeping, skip conditions (recorder injected).
